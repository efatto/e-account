This module add chatter to account fiscal position, allowing tracking of
changes with module tracking_manager.

Usage
=====

Dopo aver installato il modulo e installando il modulo tracking_manager,
è possibile abilitare la tracciatura dei vari campi della posizione
fiscale (vedasi documentazione sul modulo citato).
