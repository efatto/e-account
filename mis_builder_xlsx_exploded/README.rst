Configuration
=============

Impostando i campi di cui si vuole vedere il dettaglio tramite il check:

.. image:: https://raw.githubusercontent.com/efatto/e-account/12.0/mis_builder_xlsx_exploded/static/description/mostra_dettagli.png
    :alt: Mostra dettagli

si ottiene l'esportazione dettagliata cliccando, a scelta, sul bottone presente nel report:

.. image:: https://raw.githubusercontent.com/efatto/e-account/12.0/mis_builder_xlsx_exploded/static/description/esporta.png
    :alt: Esporta

oppure su quello presente nella preview del report:

.. image:: https://raw.githubusercontent.com/efatto/e-account/12.0/mis_builder_xlsx_exploded/static/description/esporta_da_preview.png
    :alt: Esporta da preview

Il nome del campo di dettaglio viene impostato di default, si può decidere di impostarlo in maniera più precisa tramite il campo `Espressione per il calcolo del nome della cella nel report xlsx` nel KPI relativo:

.. image:: https://raw.githubusercontent.com/efatto/e-account/12.0/mis_builder_xlsx_exploded/static/description/espressione_per_nome.png
    :alt: Espressione per nome
