Configuration
=============

Nella configurazione del magazzino viene aggiunto un menu:

.. image:: https://raw.githubusercontent.com/efatto/e-account/14.0/translation_export/static/description/menu_traduzioni.png
    :alt: Menu traduzioni

In cui si può creare una voce per esportare manualmente tramite il bottone a video o automaticamente tramite il cron sottoindicato una traduzione dei nomi dei prodotti. La traduzione viene salvata negli allegati del record, visibili sotto.

.. image:: https://raw.githubusercontent.com/efatto/e-account/14.0/translation_export/static/description/traduzioni.png
    :alt: Traduzioni

.. image:: https://raw.githubusercontent.com/efatto/e-account/14.0/translation_export/static/description/cron_traduzioni.png
    :alt: Cron traduzioni

L'esportazione può essere forzata tramite questo bottone:

.. image:: https://raw.githubusercontent.com/efatto/e-account/14.0/translation_export/static/description/esporta_traduzioni.png
    :alt: Esporta traduzioni

Il numero massimo di esportazioni salvate può essere ridotto modificando il valore di questo campo:

.. image:: https://raw.githubusercontent.com/efatto/e-account/14.0/translation_export/static/description/numero_massimo_esportazioni.png
    :alt: Numero massimo esportazioni
