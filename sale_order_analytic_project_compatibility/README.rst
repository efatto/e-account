Simple module to ensure project analytic account and analytic account of the sale order are the same.

**Table of contents**

.. contents::
   :local:

Usage
=====

Create a sale order and assign a project, than assign an analytic account different from the one present in the project. The project will be removed from the sale order.

Assigning an analytic account will assign a project if there is only one with that analytic account.
